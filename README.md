# Not Enough Servers (NES) for Horizon 26.3

A clean-room open-source client-side QoL mod for Horizon 26.3, designed to supercharge the multiplayer server menu with advanced management features.

## Features
- **Server Pinning:** Pin your favorite servers to the top of the list.
- **Recently Played:** Automatically tracks a clean history of recently joined servers.
- **Custom Categorization:** Organize servers into custom groups.

## Open Source
Built with Rust and native Horizon mixins for WebGPU / WASM and native clients.
